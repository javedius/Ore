# Caliper — дизайн-бриф

SQLite editor (Tauri 2, macOS / Windows / Linux) · макеты: `design/` · октябрь 2026

## Направление

**Caliper** — плоский инструментальный интерфейс в духе прецизионного измерительного прибора: штангенциркуль не украшает деталь, он точно её показывает. Вся структура нарисована волосяными линиями 1px и тремя уровнями поверхности — ни одного градиента, блюра или статичной тени; тень живёт только у всплывающих слоёв. Грид данных — главный герой окна, хром занимает минимум места, а выполняемый SQL виден прямо в статус-баре: инструмент ничего не прячет. Один петрольный акцент обслуживает весь интерактив; красный и янтарный зарезервированы под семантику ошибок и несохранённых изменений.

## Палитра

Роли одинаковы в обеих темах; значения подобраны с контрастом ≥ 4.5:1 для текста.

| Роль | Dark | Light |
|---|---|---|
| bg-app (рабочая область, грид) | `#15191A` | `#FFFFFF` |
| bg-panel (сайдбар, тулбары, меню, диалоги) | `#1B2022` | `#F4F6F5` |
| bg-surface (поля ввода, шапка грида) | `#22282A` | `#EBEFED` |
| bg-inset (SQL-редактор) | `#101415` | `#F7F9F8` |
| line / line-strong (волосяные линии) | `#272E30` / `#37403F` | `#E3E8E6` / `#C8D1CE` |
| text-1 / text-2 / text-3 | `#DDE4E2` / `#9AA7A4` / `#7C8986` | `#1C2624` / `#566461` / `#6A7874` |
| **accent «петроль»** (интерактив, выделение) | `#53C7B4` | `#0C6D60` |
| error (только ошибки) | `#F0887A` | `#B23A2C` |
| warn (предупреждения, несохранённое) | `#D9A85B` | `#8F6415` |

Выделение — полупрозрачный петроль: строка `13%` (dark) / `11%` (light), активная строка при правке — `22%` / `19%`. Прозрачные эквиваленты продублированы непрозрачными токенами (`--*-o`) для sticky-ячеек.

## Типографика

Только системные стеки, без CDN — приложение ~10 МБ не тащит шрифты.

- **UI:** `-apple-system / SF Pro Text` → `Segoe UI` → `Ubuntu / Cantarell`.
- **Код и данные:** `ui-monospace / SF Mono` → `Cascadia Code` → `JetBrains Mono` → `Menlo / Consolas`.
- Шкала: 15/600 (заголовки диалогов) · 13 (база) · 12.5 (грид, элементы) · 12 (моно-данные) · 11 (мета, статус-бар) · 10.5 (типы колонок, история). Межстрочные: 1.45 UI, 1.6 редактор.
- Все числа, даты, суммы — моноширинно с `font-variant-numeric: tabular-nums`; числовые колонки выравниваются вправо.
- Подписи — sentence case, без ALL-CAPS.

## Сетка и отступы

Базовый шаг **4px**; отступы 4/8/12/16/20/24. Высоты: тайтлбар 40, вкладки 34, тулбар 38, шапка грида 32, строка фильтров 28, строка данных 28, пейджер 34, статус-бар 26, инпут/кнопка 26. Сайдбар 248px, гуттер rowid 46px, история 244px. Радиусы: 3px (чипы) → 5px (кнопки, инпуты) → 8px (меню, дропзоны) → 10px (диалоги); ячейки грида — без скруглений. Тень одна: `0 4px 18px rgba(0,0,0,.45)` (dark) / `.14` (light) — только меню и диалоги.

## Состояния

- **hover** — `5%` чернения/беления поверхности, без сдвигов и роста;
- **selected** (строка/пункт) — петрольная заливка `13%/11%` + петрольный номер rowid в гуттере;
- **editing** — inline-input поверх ячейки: фон bg-app, контур 1.5px петроль, каретка петрольная; строка получает усиленную заливку и янтарную точку в гуттере; подтверждение Enter / отмена Esc объясняются чипом в статус-баре;
- **NULL** — курсивный приглушённый `NULL` без рамки: «пустота» не оборачивается в объект;
- **BLOB** — рамочный чип `BLOB (1.2 KB)` моноширинно: бинарный объект «упакован»;
- **error** — красный текст/иконка, волнистое подчёркивание проблемного фрагмента в редакторе, сообщение в стиле sqlite (`near "FROM": syntax error`) + строка:символ + подсказка;
- **несохранённое** — янтарная точка: на вкладке таблицы и в гуттере строки;
- **focus** — всегда видимый контур 2px петролем (`:focus-visible`), у полей — кольцо `--focus-ring`.

## Иконки

Inline SVG, сетка 16, stroke 1.5, скруглённые концы, только `currentColor`. Один вес, один стиль, никакой мультикрасочности. Спрайт продублирован в каждом макете.

## Чего сознательно избегаем

Градиенты и блюр · статичные тени · цветные статус-чипы в ячейках · карточные сетки и одинаковые «коробки» · ALL-CAPS ярлыки · чистый чёрный `#000` и кислотный неон · больше одного акцента · вкладки-леса и многошаговые диалоги · декоративная анимация (движение — только ответ на действие, `prefers-reduced-motion` уважается).

## Заметки для реализации (Tauri)

- Обе темы — из одного `tokens.css`: переключатель меняет `data-theme` на `<html>`; сохранение между сессиями и `prefers-color-scheme` как значение по умолчанию.
- Traffic lights в макетах — macOS-иллюстрация; на Windows/Linux — нативный хром окна Tauri.
- Хоткеи платформенные: ⌘ на macOS, Ctrl на Windows/Linux (Run = ⌘/Ctrl+Enter).
- Тонкие скроллбары стилизованы под WebKit и `scrollbar-width: thin` — системный webview каждой ОС.
- Шрифты системные: интерфейс автоматически выглядит нативно на каждой ОС без поставки файлов.
