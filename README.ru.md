## Зачем

Ore построен вокруг одной задачи: **открыть SQLite-файл и посмотреть или поправить данные за минимум шагов** — маленькое нативное приложение (~10 МБ) вместо вкладки браузера или тяжёлой IDE.

- Открывает `.db / .sqlite / .sqlite3` за секунды — через диалог или drag & drop
- Настоящее десктоп-приложение: нативные меню, системный webview, без Electron
- Читает и пишет безопасно: каждая правка — параметризованный `UPDATE` по `rowid`, импорт CSV идёт одной транзакцией с откатом

## Возможности

- **Дерево схемы** — таблицы с колонками, типами и PK, views, индексы, триггеры, счётчики строк
- **Грид данных** — 50 строк на страницу, сортировка кликом по заголовку, правка ячейки двойным кликом, `Set NULL`, копирование ячейки / строки в JSON / CSV, добавление и удаление строк
- **Фильтры по колонкам** — подстрока по умолчанию, префикс-операторы `=`, `>`, `<` для точных и числовых сравнений
- **SQL-консоль** — запуск по ⌘/Ctrl+Enter, результаты в гриде, ошибки напрямую от SQLite, история запросов между сессиями
- **Импорт CSV** — превью, выбор разделителя (`,` `;` таб `|`), новая таблица с выводом типов по данным или маппинг на существующую; пустые поля становятся `NULL`, весь импорт — одна транзакция
- **Экспорт** — таблица (с учётом фильтров) или результат запроса в CSV / JSON
- **Тёмная и светлая темы**; views и таблицы `WITHOUT ROWID` открываются read-only

## Сборка из исходников

Нужны: [Node.js 20+](https://nodejs.org), [Rust](https://rustup.rs) и платформенные требования [Tauri](https://tauri.app/start/prerequisites/) (Xcode CLT на macOS, MSVC на Windows, webkit2gtk на Linux).

```bash
git clone https://github.com/javedius/Ore.git
cd Ore/app
npm install
npm run tauri dev     # запуск приложения с горячей перезагрузкой
```

Продакшен-сборка: `npm run tauri build`.
Тесты бэкенда: `cd app/src-tauri && cargo test`.

## Технологии

| Слой      | Выбор                                              |
|-----------|----------------------------------------------------|
| Оболочка  | Tauri 2 (системный webview, ядро на Rust)          |
| База      | rusqlite с bundled SQLite (без системных зависимостей) |
| Фронтенд  | React 19 + TypeScript + Vite                       |
| Дизайн    | собственная система «Caliper» — flat, волосяные линии, петрольный акцент |

Фронтенд не собирает SQL для правок: все стейтменты пишет сторона Rust, проверяя имена таблиц и колонок по whitelist'у и отдаёт данные страницами.

## Структура проекта

```
app/src           React UI (дизайн-токены в src/styles)
app/src-tauri     Rust-бэкенд: rusqlite, IPC-команды
docs              Скриншоты
demo              Демо-база (shop.db) и CSV для пробы импорта
```
